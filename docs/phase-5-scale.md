# Phase 5 — Scale Features

*Months 10–24 · Target 15,000 merchants*

Engineering shifts from feature-building to platform-hardening: data, integrations, and language reach.

| Feature | Primary surface(s) |
|---|---|
| Inventory management with auto sold-out and low-stock alerts | Owner dashboard |
| GST invoicing with HSN codes, GSTR-1 export | Owner dashboard, Super Admin |
| AI demand forecasting for prep quantities | Owner dashboard |
| B2B REST API for food courts, hotel chains, corporate cafeterias | Platform / API layer |
| Regional language menus — Hindi, Gujarati, Tamil, Telugu | Customer site |
| Offline mode for the merchant dashboard with sync-on-reconnect | Owner dashboard |
| ONDC network listing and discovery integration | Backend integration |

## Exit criteria

Platform processes GST-compliant invoices at scale, B2B API has at least 3 signed integrations, and offline mode is verified in low-connectivity pilot towns.
