# What Ships Alongside Each Phase

Companion UI mockups have been designed for the three core surfaces so the team can build against a shared visual reference from day one:

- **Super Admin Console** (`qrtoken-super-admin.html`) — Overview, Merchant Directory, Verification Queue, Billing, Transactions, Support, Compliance, Settings
- **Restaurant Owner Dashboard** (`qrtoken-owner-dashboard.html`) — Live Orders, Kitchen Queue, Manual Entry, Table Sessions, Cash Management, Cash Reconciliation, Refunds, Menu Manager, Coupons, Analytics, Settings
- **Customer Ordering Website** (`qrtoken-customer-site.html`) — Menu browse (with category filter & search), Cart & Checkout, Live Token Tracking

These are interactive HTML prototypes shared as separate files alongside this plan — every action button, toggle, filter, and status flow is wired up with real front-end logic (not just static visuals), so engineering can treat them as a functional spec, not just a mood board.
