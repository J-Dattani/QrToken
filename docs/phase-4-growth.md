# Phase 4 — Growth Features

*Months 4–9 · Target 3,000 merchants*

Builds directly on the Growth-phase feature set from the master documentation (Section 14), translated into build order.

| Sprint block | Feature | Primary surface(s) |
|---|---|---|
| 4a | Bill splitting — equal / by-item / custom, hybrid cash+digital | Customer site, Owner dashboard |
| 4a | Table QR codes with session-based group ordering | Customer site, Owner dashboard |
| 4b | WhatsApp order alerts to merchant's phone | Backend integration |
| 4b | Loyalty points — earn/redeem configuration | Owner dashboard, Customer site |
| 4c | Merchant mobile app (React Native), offline order viewing | Owner (mobile) |
| 4c | Kitchen Display System (KDS) — dedicated large-screen mode | Owner dashboard |
| 4d | Multi-outlet support — one login, multiple shops, central view | Owner dashboard, Super Admin |
| 4d | AI menu builder from photo; pre-order scheduling | Owner dashboard |

## Exit criteria

Platform sustains 3,000 active merchants with multi-outlet accounts live and KDS deployed to at least 50 kitchens.
